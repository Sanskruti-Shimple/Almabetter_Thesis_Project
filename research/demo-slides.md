# MarketNest presentation / demo outline

Adapt the timing to the course requirements. Capture your own screen images and demo the running application. Suggested 8–10 minute flow:

1. **Problem and motivation** — shopper needs and the chosen retail scope.
2. **Research question and objectives** — modularity, maintainability, and scalability.
3. **Architecture** — React UI → Express REST API → MongoDB; identify auth and deployment boundaries.
4. **Technology choices** — MERN, JWT, Docker, and GitHub Actions; explain why each is appropriate for this prototype.
5. **Live demo** — browse/search, filter, add/remove cart items, register/sign in, and place an order.
6. **Verification** — show actual test output and explain what tests cover and do not cover.
7. **Results and trade-offs** — present measured values only; compare the deployment options actually evaluated.
8. **Limitations and next steps** — payment integration, stock concurrency, observability, accessibility, and measured scaling.
9. **References and questions** — acknowledge sources and invite questions.

## Walkthrough checklist

- Start MongoDB, seed the catalog, and start client/API before recording.
- Use a demo-only account and do not show real secrets or personal data.
- Confirm the API and browser console are error-free.
- Keep a short recorded fallback demo in case the live environment is unavailable.
